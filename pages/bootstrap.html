A powerful, mobile-first CSS framework providing a 12-column grid system, pre-built components and responsive utility classes.

What is Bootstrap?

Bootstrap is a free, open-source CSS framework originally built at Twitter. It gives developers pre-built components — navbars, buttons, cards, alerts, grids — so you can build responsive, mobile-first websites much faster than writing CSS from scratch.

Bootstrap uses a 12-column Flexbox grid and utility classes like d-flex, mt-3, text-center and p-4 for instant layout control directly in your HTML, keeping stylesheets lean.

Example 1 — Responsive Navbar

Bootstrap's navbar component collapses to a hamburger menu on small screens using its built-in JavaScript and data-bs-* attributes — no custom JS required.

navbar.html
<nav class="navbar navbar-dark bg-dark navbar-expand-md">
  <div class="container">
    <a class="navbar-brand" href="#">Alex Portfolio</a>
    <button class="navbar-toggler"
            data-bs-toggle="collapse"
            data-bs-target="#navMenu">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="navMenu">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item"><a class="nav-link active">Home</a></li>
        <li class="nav-item"><a class="nav-link">Projects</a></li>
        <li class="nav-item"><a class="nav-link">Contact</a></li>
      </ul>
    </div>
  </div>
</nav>

Example 2 — Badges, Alerts & Progress

Bootstrap provides badge components for status labels, alert components for contextual messages, and progress bars — all with built-in colour variants via utility classes.

components.html
<!-- Badges -->
<span class="badge bg-primary">HTML</span>
<span class="badge bg-success">CSS</span>
<span class="badge bg-warning text-dark">JS</span>

<!-- Alerts -->
<div class="alert alert-info">ℹ️ Profile updated.</div>
<div class="alert alert-success">✅ Submitted!</div>

<!-- Progress -->
<div class="progress" style="height:10px">
  <div class="progress-bar bg-success" style="width:82%"></div>
</div>

Example 3 — Responsive 12-Column Grid

Bootstrap divides rows into 12 columns. col-md-3 means 3/12 (25%) on medium screens and above, stacking to full-width on mobile. This makes layouts responsive by default.

grid.html
<div class="row g-3">
  <!-- 3/12 cols = 25% each on md+ screens -->
  <div class="col-12 col-md-3">🖥️ Frontend</div>
  <div class="col-12 col-md-3">⚙️ Backend</div>
  <div class="col-12 col-md-3">🗄️ Database</div>
  <div class="col-12 col-md-3">🚀 DevOps</div>
</div>
