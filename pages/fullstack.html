What is Full Stack Development?

Full Stack Development means building both the client-facing side of a web application (the front-end) and the server-side logic and data management (the back-end). A Full Stack Developer understands the complete journey of a web request — from a user clicking a button, to a server processing logic, to a database storing the result.

Common stacks include the MERN stack (MongoDB, Express, React, Node.js) and the LAMP stack (Linux, Apache, MySQL, PHP). The key advantage is the ability to own an entire feature — writing the UI, the API, and the database schema without handoffs.

Back-End Example — Node.js + Express API

A minimal REST API route built with Node.js and Express. The server listens for a GET request and returns a structured JSON response — this is how front-end apps fetch data from a back-end.

server.js
const express = require('express');
const app = express();

// GET endpoint returns developer info as JSON
app.get('/api/developer', (req, res) => {
  res.json({
    name:  "Tojang Gurung",
    role:  "Full Stack Developer",
    stack: ["React", "Node.js", "MongoDB"],
    open:  true
  });
});

app.listen(3000, () =>
  console.log('API → http://localhost:3000')
);
JSON Response from GET /api/developer

Database Example — SQL (PostgreSQL)

Creating and querying a projects table using SQL. Relational databases store data in structured tables — queries let us retrieve, filter and join that data efficiently.

projects.sql
CREATE TABLE projects (
  id      INT PRIMARY KEY AUTO_INCREMENT,
  title   VARCHAR(100),
  tech    VARCHAR(100),
  status  VARCHAR(20)
);

INSERT INTO projects (title, tech, status) VALUES
  ('Analytics Dashboard', 'React, MongoDB',      'Live'),
  ('Study Planner',      'Vanilla JS, CSS Grid', 'Live'),
  ('Recipe Finder API',  'Express, PostgreSQL', 'In Progress');

SELECT * FROM projects;
